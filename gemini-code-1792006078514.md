# Book Tracker

A simple, responsive web application to keep track of books you want to read, are currently reading, or have finished. Built with plain HTML, CSS, and JavaScript.

## Features
- **Add Books**: Input a title and author to add a book to your list. Title and author are required fields.
- **Status Tracking**: Categorize books as "To read", "Reading", or "Finished".
- **Local Storage**: Data is saved in the browser, so your list remains intact even after refreshing the page.
- **Search**: Instantly filter your book list by title or author.
- **Statistics**: View a real-time count of your books categorized by their status.
- **Mobile Friendly**: Designed to work perfectly on desktop, tablet, and mobile devices.

## How to Run
Since this app uses vanilla web technologies, no server or database is required. 
Simply open `index.html` in any modern web browser to start using the app!
